# AI 电话阶段 B 联调验收

日期：2026-10-29。状态：待真实电话验证。单元测试不能代替本表。

## 环境与安全

- 使用隔离测试环境、测试号码、测试助手和已发布测试流程，不在生产通话中注入故障。
- 先确认 Java、FreeSWITCH、UniMRCP 插件版本及 Lua 脚本一致；本批修改在 Java，未改插件或 Lua。
- “停播重试失败后”默认挂断；测试转人工时明确选择测试技能组，并确保有人签入可接听。
- 收集同一 businessCallId / customerLegUuid、turnId、seq、generation 对应的 Java、FreeSWITCH、UniMRCP 日志，核对时区。共享日志前去掉号码、身份资料和凭据。
- 不通过停掉生产 ESL 或关闭云安全组来制造故障。停播超时和处置错误的注入优先由模拟网关完成。

## 必测场景

本轮统一测试更新要求：后端重新打包部署；若尚未更新“停播失败处置”下拉配置，同时更新前端。无需本批数据库迁移，也无需因本批 Java 修改重新编译 UniMRCP 插件或替换 Lua。已有插件/Lua 版本仍需与先前语音链路修改匹配，不代表任意旧版本都能使用。

先在各播报节点确认“停播重试失败后”选项。默认挂断，选择转人工时必须指定可接听的测试技能组。测试完成前不要切换生产流量。

## 链路证据

命令返回成功只证明 FreeSWITCH 接受了命令，不能独自证明客户侧音频缓冲已排空。需同时核对客户听感/测试录音、播放结束或取消事件、插件轮次日志和 Java 下一轮识别时点。无事件或插件未确认取消的情况单独记录，不按“日志无异常”判通过。

分别记录识别结束到后端、后端理解完成、TTS 首音频、实际播放结束、下一次识别启动的耗时，不混成一个总超时。记录实测值后确定验收阈值，不在未测量前承诺响应时间。
