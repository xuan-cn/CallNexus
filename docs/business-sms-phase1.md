# 业务短信管理：第一阶段

## 范围与入口

- 顶层菜单“短信管理”：短信渠道、短信模板、发送记录。
- 客户详情/坐席工作台客户卡片：“发送短信”，抽屉内可预览、发送和分页查看该客户发送记录。
- 首期支持阿里云、腾讯云的中国大陆手机模板短信，不支持任意自由文本群发或国际号码。
- 现有 YML 中 config1/config2 登录验证码配置保持不动。业务发送使用独立服务商实例，不写回 YML，不覆盖 SmsFactory 现有实例。
- 本阶段没有接入资料变更自动触发、工单事件、外呼结果或 AI 流程节点。后续可复用 BusinessSmsService 入队服务，但必须增加对应权限、收件人校验和事件幂等标识，不能让 AI 任意调用发送接口。

## 配置步骤

1. 升级前备份数据库，执行 `V161__add_business_sms.sql`，或通过项目正常 Flyway 升级机制执行，二者不要重复执行。
2. 更新前后端，重新登录刷新菜单和权限缓存。
3. 新建渠道：选择阿里云/腾讯云，填写短信服务账号 AccessKey ID/Secret、已审核签名；腾讯云还需 SDK App ID。
4. 新建模板：选择渠道，填写服务商已审核模板编号。这里不会代替服务商模板申请/审核。
5. 正文以 `${name}` 标识变量；变量来源为客户姓名、客户主号码或人工填写。正文与服务商已审核内容必须一致，不含重复签名。
6. 腾讯云使用 `${1}`、`${2}`，变量按 1、2、3 顺序配置，顺序就是发送参数顺序。
7. 先测试自己的号码。测试发送同样真实计费，需要模板及渠道已启用，并计入限频。
8. 到客户详情发送：选择客户已启用的大陆手机号、模板，补齐手动变量，预览，确认费用后提交。自动变量从数据库读取，不允许坐席覆盖。

凭证加密存储，读取接口只返回“已配置”标记。编辑时密钥留空表示保持不变。保持系统数据加密密钥稳定，否则旧凭证无法解密。停用渠道会阻止尚未提交的队列消息；发送审计记录不删除。

## 权限

| 能力 | 权限 |
| --- | --- |
| 短信管理菜单 | callcenter:sms:view |
| 渠道列表 | callcenter:sms-channel:list |
| 新建/编辑/停用渠道 | callcenter:sms-channel:manage |
| 测试发送及测试模板选项 | callcenter:sms-channel:test |
| 模板列表、渠道选项 | callcenter:sms-template:list |
| 新建/编辑/停用模板 | callcenter:sms-template:manage |
| 全租户发送记录 | callcenter:sms-record:list |
| 客户发送、预览、选项及该客户历史 | callcenter:customer:sms |

“客户发送短信”权限挂在客户管理菜单下，坐席无需短信管理后台权限。客户接口先检查现有客户数据访问范围；只能向该客户已启用号码发送。全租户记录权限应只授予主管/管理员，记录含号码和正文。

模板配置人员需要“模板查询+模板配置”；渠道配置人员需要“渠道查询+渠道配置”。测试人员还需渠道查询以进入测试入口。新增权限默认关联管理员角色，其他角色需人工授权。

## 发送与防重

请求先持久化到 `cc_sms_send_record`，后台每 3 秒扫描、最多 2 个并发提交，不依赖 SnailJob 启用状态。入队接口返回记录编号，不是送达结果。

| 状态 | 含义 |
| --- | --- |
| QUEUED | 等待提交 |
| PROCESSING | 正在向服务商提交 |
| ACCEPTED | 服务商已受理，不代表已送达 |
| REJECTED | 渠道停用/变更等提交前拒绝，或服务商明确业务拒绝 |
| UNKNOWN | 网络/SDK 异常、无法确认的响应，或提交状态超过 5 分钟未恢复 |

不自动重试 UNKNOWN/REJECTED。超时后服务商可能已接收请求，重试必须先人工核实；本期无“重发”按钮。SMS4J 自带重试为 0。

业务短信 HTTP 请求独立设置连接 10 秒、读取 20 秒超时。仅在业务短信发送线程的作用域内应用，不修改登录验证码或其他 HTTP 请求的默认超时。

- requestId 在租户内唯一，相同标识/内容只保留一条记录，改内容不能复用旧标识。
- Redis 对租户+号码串行预留名额，数据库事务提交后释放锁；多实例通过条件更新领取。
- 同租户同号码所有渠道、所有状态（含测试、拒绝和未知）都计数；当前渠道配置决定本次上限。默认每分钟 1 条、每日 30 条。
- 时间窗口使用服务端时间，生产部署应保持时区一致。
- 尚未接入回执，不能从 ACCEPTED 推断 DELIVERED。
- 客户保存接口不调用短信；短信失败不回滚客户资料。

## 验收清单

1. 验证渠道密钥在库中为密文，接口无原文；编辑其他字段不丢失凭证。
2. 验证阿里云命名变量、腾讯云位置变量；重复、缺失、错序和未知变量被拒绝。
3. 普通坐席只授权客户短信，可预览/发送及查本客户历史；不能访问管理记录、其他客户或任意号码发送。
4. 同 requestId 连续/并发提交只产生一条记录；改内容复用标识被拒绝。
5. 检查分钟/日上限、跨渠道/测试计数、多实例领取。
6. 模拟 SDK 超时，记录 UNKNOWN 且不重发；停用渠道后排队记录不调用服务商。
7. 核对正文、签名、号码、变量和服务商受理记录。单元测试/浏览器模拟不实际发短信，真实发送与计费需部署后用自己的号码验收。
8. 登录验证码仍走原 YML 配置。

## 限制

- 没有送达回执、主动查询送达、自动重发、群发、业务事件绑定。
- 渠道和模板采用停用管理，不提供删除入口，保护审计关系。
- 自动映射仅客户姓名/主号码，其他字段先手工填写，不执行任意表达式。
- 本地预览不会自动核验服务商审核正文，管理员需保证一致。
- 数据库迁移和真实服务商发送仍需部署验收，不要对生产客户做测试发送。
