## 目标与边界

从逐句话术、等待、意图节点和大量连线，改为业务步骤驱动。客户提供的业务主线和必要告知保持可控，AI 负责步骤内理解、插问、澄清，不擅自推进或写入业务数据。不要求兼容旧流程数据，但本次不自动删除数据库中的流程和执行记录。

不把所有判断都交给大模型：明确回答走当前步骤绑定的快速规则，复杂表达先分类，系统校验完成条件。目标是融合分类、信息提取和候选回复；当前文本收集和知识问答仍可能额外调用模型，不能宣称已合并为一次请求。不能把“是的”作为脱离当前问题的全局确认。

## 现状核查

- 编辑器：`AiWorkflowDesigner` 使用 LogicFlow，执行定义为 nodes / edges / settings；节点配置集中在 nodeRegistry。
- 执行器：`AiWorkflowRuntimeServiceImpl` 与节点 handler 负责播报、等待、分支、业务操作。
- 电话运行：`AiRealtimeMrcpEventService` 已有播报对象、轮次 generation、事件去重、挂断保护和节点打断配置。后续基于实际路径整合，不再添加另一套并行控制链。
- 现有普通节点打断值：INHERIT / DISABLED / INTERRUPT / CONTROL_RESUME；新增固定模板必要告知的独立禁止/回答后补播策略与事件级状态记录。“助手全局强制禁止”尚未实现，不能当作已有功能。

## 运行协议

### 状态与事件

建议状态：PREPARING、SPEAKING、LISTENING、UNDERSTANDING、EXECUTING、TRANSFERRING、ENDING、ENDED、FAILED。所有异步回调经统一入口校验 callId / stepExecutionId / turnId / operationId 后转换状态；终止状态不能被旧事件重新激活。

首包可播放、插件缓冲、真正播放完成必须分开。不能凭文字日志认为已播完，也不能凭固定时长直接推进。超时应检测通道和操作状态，有限恢复后明确转人工或结束，避免永久无响应和无限重试。

### 打断与控场

- 助手提供默认策略及可选的全局强制禁止；节点选择继承、禁止、允许直接回应、允许控场。全局禁止优先，UI 必须说明有效结果。
- 必要告知与普通解释允许分别配置。禁止打断时可预热资源，但未到有效收音阶段的输入不得推进业务；禁止用重复关闭/重开造成收音空窗。
- 允许打断：语音活动触发停止播放和剩余生成，完整有效文本再触发理解。噪声或空结果不推进。
- 控场替换原话术，不接着重播原文；次数达到上限后仍允许打断，只停止控场。控场本身默认不嵌套控场。
- 被打断的必要告知未完成，不能标记已告知。再次补充应依据完成账本，不盲目重播整段。
- 按识别事件标识去重，不按文本去重。不同轮次的“没有”“是的”必须正常处理。

### 理解与推进

输入分类：当前问题回答、业务插问、信息更正、拒绝/转人工/稍后联系、澄清、超范围。正常插问不计入识别失败；沉默、无效音频和语义澄清分别计数。

模型返回受约束结构：分类、提取字段、原文证据、候选回复、候选完成条件。系统仅接收白名单字段，验证类型、证据和完成条件；模型不可任意指定节点或写库。知识回答仅使用获准依据；没有依据时澄清或转人工。回答插问后留在当前步骤，不能默认继续。

性能：固定话术可预合成；仅携带当前目标与必要历史；不串联“识别意图模型”和“回复模型”；解释可流式播报，但业务推进必须等完整结构校验。响应耗时需实测，不作固定毫秒承诺。

### 本批修改

- 普通打断原先先 getAndSet(null)，随后才判断允许与否；禁止打断或并发替换时可能错误摘除活动播报，后续完成事件无法正常接续。改为先取快照并验证策略，再按对象身份 CAS 取得取消所有权。拒绝和迟到请求都不修改活动对象。
- 无轮次标识的文本兜底从“任意包含当前文本”收紧为完整文本相等或标准 speak 参数末尾完整匹配；旧长句包含当前短句不再误完成当前播放。已有 turnId/seq/generation 校验优先级不变。
- 新增播放所有权测试：禁止打断保留对象、迟到打断不删除新播放、取消与完成互斥、5 个竞争线程仅一个成功、其他会话不受影响、旧长句匹配防护。

### 第三批：播放状态转换的会话级短锁

- 新增会话级 playbackTransitionLock；正常播放注册、完成/超时/普通打断/控场/WS 提前完成的播放认领，以及挂断关闭使用同一锁域。公共 claimPlaybackTransition 一次性验证关闭状态、轮次和对象身份，清理等待标记及计时器，必要时失效轮次。

- 流程上下文记录 PENDING / INTERRUPTED / PLAYBACK_COMPLETED；测试台显式模拟完成为 SIMULATED_COMPLETED。挂断为 ABORTED；公共转接/结束处置可中止告知，记录 CANCELLED_BY_RULE，不能混同已告知。当前只支持模板，不支持自由模型段或媒体告知；不是客户已听清/同意的证明，MRCP 错误原因、HTTP 异常及真实音频排空仍待现场验证。

- 沉默仅消费显式无输入超时完成原因，closed/空结果/接口错误不直接计数；未透传原因时保留旧识别保护。排队处理加入有效输入序号检查，避免新输入到达后再执行旧沉默处置。真实电话的事件头透传尚待核对，不能以模拟事件测试替代。
